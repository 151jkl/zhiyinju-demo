# 知音局 · 基于知乎内容痕迹的同频匹配 Demo

知音局不是用几个标签把人简单归类，而是从用户在知乎主动点赞、收藏、关注和持续阅读过的内容里，找出真正让两个人停留过的共同问题，再把这条内容关系画出来。

## Demo 亮点

- 关系地图：用节点和关系线展示共同内容如何形成连接
- 同频匹配：匹配卡展示观点、活跃程度和可验证的共同兴趣
- 热点联动：知乎热榜负责发现当下讨论，知乎搜索与全网搜索负责补足背景
- 观点圆桌：从一个具体问题进入讨论，支持发布第一句观点
- 知乎 OAuth：授权后读取公开昵称、创作、关注和收藏信息
- 编辑画像：调整表达签名和兴趣坐标，影响下一次匹配展示

## 本地运行

```powershell
Copy-Item .env.example .env
# 在 .env 中填写知乎开放平台的 AccessSecret 与 OAuth App 凭证
npm start
```

打开 `http://localhost:5173/`。

## OAuth 回调

OAuth 回调地址必须是知乎后台登记过的公网 HTTPS 地址，不能使用 `localhost`。本地演示可以使用临时隧道，但临时地址在隧道重启后可能变化。

## 安全说明

真实 `.env`、AccessSecret、OAuth App Key 和用户 Token 不提交到仓库。仓库只保留 `.env.example` 配置模板。
